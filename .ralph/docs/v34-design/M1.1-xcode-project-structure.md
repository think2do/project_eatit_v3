## 1. 目标与范围

本设计是 **M1.1.dev** 实施 Xcode 工程脚手架的唯一依据;developer 不得偏离本文件结构与字段约束。本节点只产出 design doc,**不生成 Swift 代码、不创建 `.xcodeproj`、不动 `apps/desktop/`**。

**包含**:目录树 / Build Phases 清单 / entitlements 占位与终态 / Info.plist 必需 key / SPM 依赖策略 / Vite→Resources/web 同步策略 / 工具链版本锁 / dev 实施 checklist。

**不包含**(留给后续节点):
- M1.2 — `WKURLSchemeHandler` 实现(让 `eatit-app://` 取代 `file://`)
- M1.3 — TestFlight 配置、provisioning profile、ASC API

## 3. Build Phases

Xcode → Targets → Eatit → Build Phases。共 4 个 phase,M1.1.dev 只配置前 2 个,后 2 个为占位 echo。

### 3.1 Compile Sources (Xcode 默认)
自动收集 target 内所有 `.swift`。M1.1.dev 阶段 = `EatitApp.swift` + `AppDelegate.swift` + `WebViewController.swift`。

### 3.2 Copy Bundle Resources
新增 folder reference:`$(SRCROOT)/Eatit/Resources/web`(蓝色 folder,保留目录层级)。打包后落到 `Eatit.app/Contents/Resources/web/`。

### 3.3 Run Script: 校验 entitlements 完整 (M1.4 启用,M1.1.dev 占位)

```sh
# Phase Name: "Verify Entitlements"
# Input Files: $(BUILT_PRODUCTS_DIR)/$(WRAPPER_NAME)
# M1.1.dev 占位:
echo "[M1.1.dev placeholder] entitlements verification deferred to M1.4"
# M1.4 终态(伪代码,M1.4 节点实施):
# codesign -d --entitlements - "$BUILT_PRODUCTS_DIR/$WRAPPER_NAME" \
#   | grep -q '<key>com.apple.security.app-sandbox</key>.*<true/>' \
#   || { echo "FATAL: app-sandbox entitlement missing"; exit 1; }
```

### 3.4 Run Script: 校验内嵌二进制 Team ID 一致 (M1.4 启用,M1.1.dev 占位)

```sh
# Phase Name: "Verify Embedded Binary Team ID"
echo "[M1.1.dev placeholder] team-id sweep deferred to M1.4"
# M1.4 终态:遍历 .app 内 frameworks/helpers,codesign -dvvv 抓 TeamIdentifier,
# 与主二进制 TeamIdentifier 比对,任一不一致 exit 1。
```

## 4. Entitlements 字段(占位 + 终态)

### 4.1 M1.1.dev 占位(让 build 通过即可)

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>com.apple.security.app-sandbox</key><true/>
    <key>com.apple.security.network.client</key><true/>
</dict>
</plist>
```

### 4.2 M1.4 终态(规范文,引 PRD §4.3)

在 4.1 基础上追加 3 项:`files.user-selected.read-write` / `device.audio-input` / `keychain-access-groups`(`$(AppIdentifierPrefix)com.eatit.desktop`)。

### 4.3 严禁项白名单(constraints §A0.2,触发任一 = Ralph loop 立即停下报告)

| Key | 原因 |
|---|---|
| `com.apple.security.network.server` | Swift 直接出站,无本地端口 |
| `com.apple.security.cs.disable-library-validation` | 无 Python sidecar / 未签 .so |
| `com.apple.security.cs.allow-unsigned-executable-memory` | 无 JIT 需求 |
| `com.apple.security.cs.allow-jit` | 无 JIT 需求 |
| `com.apple.security.cs.allow-dyld-environment-variables` | 无动态注入 |
| `com.apple.security.inherit` | 无子进程 |

**红线**:任何 commit 试图加入以上 key = A0.2 违反,立即报告。

## 7. Vite Build → Resources/web/ 同步策略

### 7.1 总原则

**build-time 同步,严禁运行时拉取**(constraints §A0.5)。Resources/web/ 内所有产物在 codesign 时已固化,运行时只读。

### 7.2 流程(M1.2 接通 Vite,M1.1.dev 仅占位)

Xcode → Eatit target → Build Phases → 新增 Run Script(置于 Compile Sources **之前**,New Run Script Phase → 拖到顶部):

```sh
# Phase Name: "Sync Vite Build to Resources/web"
# M1.1.dev 占位:不接 Vite,Resources/web/index.html 手写。
echo "[M1.1.dev placeholder] vite sync deferred to M1.2"

# M1.2 终态(伪代码):
# set -euo pipefail
# cd "$SRCROOT/../../"                                   # → repo root
# corepack pnpm --filter @eatit/desktop build            # 产 apps/desktop/dist/
# rsync -a --delete \
#   "$SRCROOT/../../apps/desktop/dist/" \
#   "$SRCROOT/Eatit/Resources/web/"
```

### 7.3 M1.1.dev 占位 `Resources/web/index.html`

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head><meta charset="utf-8"><title>Eatit v3.4</title></head>
<body><h1>Hello, Eatit v3.4</h1></body>
</html>
```

### 7.4 路径纪律(constraints §B4)

- 全用 `$(SRCROOT)` / `$(PROJECT_DIR)` / `$(BUILT_PRODUCTS_DIR)`
- **禁止** hard-code `/Users/<name>/...`
- 跨工作区相对引用:`$(SRCROOT)/../../apps/desktop/`

## 10. 风险与开放问题

### 10.1 file:// 在 Sandbox 下加载 Resources/web/index.html
WKWebView 用 `loadFileURL(_:allowingReadAccessTo:)` 加载 bundled `index.html`,Sandbox 下应可工作(read access 限制在 bundle 内)。M1.1.dev 实地验证;若失败,M1.2 通过 `WKURLSchemeHandler`(自定义 `eatit-app://` scheme)解决——这正是 M1.2 的设计目标。

### 10.2 Vite 产物的 asset 相对路径
Vite 默认 `base: '/'` 在 file:// 下会失败。M1.2 接通 Vite 时需在 `apps/desktop/vite.config.ts` 设 `base: './'`(M1.1.dev 不动 vite.config.ts;M1.2 节点处理)。

### 10.3 Xcode 26 默认设置漂移
Xcode 26 比 15.4 新增的默认值需 M1.1.dev 实地核对:
- Hardened Runtime 是否默认开(预期开,不影响 sandbox)
- Swift Strict Concurrency 默认级别(预期 minimal)
- Swift language mode(预期 Swift 5,不切 Swift 6 严格并发)

任一项与本设计冲突 → developer 在 dev loop 报告,**不擅自调整**。

### 10.4 Bundle Identifier 与 Keychain Service 一致性
所有 Keychain 写入用 Service = `com.eatit.desktop`(constraints §C1)。Bundle Identifier 必须严格 = `com.eatit.desktop`,不得带 `.app` / `.macos` 后缀,否则 keychain-access-groups 与运行时 Bundle ID 错配 → Keychain API `errSecMissingEntitlement`。

### 10.5 EatitTests target 的 sandbox 继承
Xcode 默认创建 Test target 不会继承主 target 的 entitlements。M2.x 节点编写单元测试时,若测到需要 sandbox 容器路径的 Service(如 DatabaseService),需为 Test target 单独配置 entitlements;本节点不做此事,只占位空 target。
