### 🔴 严重

#### 🔴-1. 截图 PNG 实体文件缺失 — 直接阻塞 App Store 提交

- **发现**:`apps/macos/AppStore/screenshots/` 仅有 `.gitkeep` + `SHOOT_GUIDE.md`,5 张 PNG(01-onboarding / 02-upload-parse / 03-live-caption / 04-report / 05-dashboard)未生成。SHOOT_GUIDE 已记录"实际 PNG 拍摄在 Helper-developer 子 loop 或 M6.5 archive 阶段执行"。
- **Apple 规则**:Mac App 至少 1 张有效截图(1280×800 或 2560×1600)才能进 Review queue;截图字段为空 → "Submit for Review" 按钮不可点击。
- **阻塞性**:🔴 阻塞 M6.5。
- **修复**:M6.5 前插入独立 Helper-developer 子 loop,完整拍摄流程(build → seed demo data → capture 5 → sips 缩图 → commit)。预计工时 1-2 小时。

#### 🔴-2. zh metadata Description 联网情报措辞与代码默认值矛盾

- **发现**:`metadata.zh.md` Description 「核心能力」第 1 条写"AI 同步抓取联网情报",语义暗示自动运行;但代码默认值为**联网情报检索默认关闭**(opt-in)。
- **对比**:en Description 同位置写"run **optional** connected web research",正确;privacy-policy.zh §4.3 写"该功能默认关闭"。
- **风险**:Apple Reviewer 操作后发现功能不自动执行 → 可能触发"功能描述不符"拒审;用户期望落差 → potential complaint。
- **修复**:zh Description 改为"AI **可选**联网情报检索(默认关闭)"或在句末补注"联网情报检索默认关闭,可在设置中启用"。
- **阻塞性**:🔴 严重(可能拒审),不属于技术构建阻塞;可与 PNG 拍摄并行。
